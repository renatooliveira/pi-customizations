# Pi customizations

Personal [Pi](https://github.com/earendil-works/pi) extensions and skills.

## Extensions

- [`compact-shell.ts`](extensions/compact-shell.ts) — Compact shell and codemode output; expand with Ctrl+O.
- [`profile-banner.ts`](extensions/profile-banner.ts) — Persistent profile banner: purple for work, blue for personal.
- [`notify.ts`](extensions/notify.ts) — Native macOS notifications when Pi is ready for your next message, including in Rio.
